I made this project in the 11th grade for the class Interdisciplinary Study and Mentorship. Under the mentorship of an employee from Corning Optical Communications, I designed a system that calculated the runtime of sprinklers on a household lawn, using data referenced from the internet and a network of physical sensors. Though I only tested it with a prototype, my tests concluded that my system could reduce water usage by up to 30% compared to traditional systems.
